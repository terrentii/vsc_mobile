# Под-проект 5: интерфейс, фоновый сервис, уведомления — спека

Часть дизайна `2026-10-22-mys-android-design.md` (§4). Логика режимов уже есть
(`:p2p`, `:central`, vault); здесь — экраны, жизненный цикл и фон.

## Решения

- **Стиль** — дизайн-система десктопа: токены `DARK`/`LIGHT` из
  `vsc_desktop/src/mys_ui/theme.py`, ГОСТ-шрифты (как в `main` десктопа; Museo не
  берём — «All rights reserved»), брутализм: рамка 2dp, жёсткая блочная тень
  4dp, капс у кнопок/заголовков, кобальтовый акцент. Material не используется —
  свои компоненты на `compose.foundation`.
- **Навигация** — одно Activity, состояние экрана в Compose (без navigation-lib):
  разблокировка → главный (вкладки `P2P | ЦЕНТР`) → чат / настройки.
- **Диалоги — оверлей в том же окне**, не `Dialog`: отдельное окно не наследует
  `FLAG_SECURE`. `FLAG_SECURE` на окне Activity.
- **Процесс** — `AppGraph`: открытый vault, `P2PService`, `CentralService`,
  счётчик изменений для UI, онлайн/ожидание P2P, поток ошибок.
- **Фон** — foreground service типа `remoteMessaging` (не `dataSync`: на
  targetSdk 35 он ограничен 6 ч/сутки). Включён по умолчанию, выключается в
  настройках. `START_NOT_STICKY`: после гибели процесса vault закрыт — без
  пароля перезапуск бессмыслен.
- **Уведомления** — «Новое сообщение» без текста и отправителя, только когда
  приложение не на экране.
- **Автоблокировка** — при возврате в приложение после N минут бездействия
  (по умолчанию 10; 0 — никогда): сервисы останавливаются, vault закрывается.
- **Адрес сервера** — настройка (по умолчанию `https://soufos.ru`); rendezvous
  выводится как `wss://<хост>/p2p`.
- **Биометрия** — `BiometricPrompt` с `CryptoObject` над `BiometricKey`;
  смена пароля сбрасывает обёртку (ключ БД меняется).

## Экраны

- Разблокировка: создание (пароль ×2, ≥ 8 символов) / ввод / отпечаток; ошибки
  неверного пароля и блокировки с остатком времени.
- Главный: вкладки, список бесед (точка «онлайн» в P2P), «+ Новый канал» (фраза)
  / «+ Новая комната», «Войти по коду», в «Центре» без сессии — форма входа.
- Чат: шапка (код комнаты / статус пира), окно ожидания пира с отменой,
  «Выйти на связь», лента (автор, время, статус, превью картинок, файлы с
  сохранением), ввод + вложение; в «Центре» — ответ/правка/удаление долгим
  нажатием.
- Настройки: тема, фон, биометрия, автоблокировка, адрес сервера, стирание
  истории «Центра» при выходе, выход из аккаунта, duress, смена пароля, замок.

## Тесты

- Compose UI на эмуляторе: создание хранилища → главный, замок → неверный и
  верный пароль, вкладка «Центр» без сессии → форма входа, чат показывает
  сохранённые сообщения.
- **Живой P2P телефон ↔ десктоп через `wss://soufos.ru/p2p`**: инструментальный
  тест с фразой из аргумента + `tools/desktop_peer.py` на хосте.
