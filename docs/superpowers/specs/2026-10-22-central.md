# Под-проект 4b: «Центр» на телефоне — спека

Часть дизайна `2026-10-22-mys-android-design.md` (§3 «Центр»). Эталон —
`vsc_desktop/src/mys_centralized` (`main` + вход по коду). Серверная часть —
`vsc_web` (Bearer-API, `/ws`, `POST /api/rooms/join`).

## Объём

- REST (`/api/auth/register|login|logout`, `/api/rooms`, `POST /api/rooms`,
  `POST /api/rooms/join`, история по курсору, `POST /api/messages` с
  `client_msg_id`, edit/delete, медиа upload/download, `reply_to`).
- WebSocket `/ws`: `auth` → `ready` → `message` / `message_edited` /
  `message_deleted`; реконнект с backoff и джиттером; `AuthException` терминальна.
- Синхронизация как у десктопа: комнаты → беседы (`room_id` = строка серверного
  id), история по курсору `central.cursor.<id>`, коды `central.code.<id>`, дедуп
  по серверному id / `client_msg_id` / телу собственного эха, оптимистичная
  отправка (pending → sent / failed), ленивая докачка медиа.
- Сессия аккаунта в vault (`central.server_url|username|user_id|token`),
  `resume()` при старте, протухший токен ⇒ сессия стирается; «стирать историю при
  выходе» (`central.wipe_on_logout`). Опрос списка комнат раз в 20 с.

## Отличия от десктопа (сознательные)

- Нет allowlist расширений: сервер снял лимиты (b7cfe1d). Клиентский потолок
  файла 50 МБ — защита памяти телефона.
- Операции синхронизации сериализованы одним мьютексом (ws, опрос, создание/вход)
  — у десктопа это даёт однопоточный event loop.
- MIME входящего вложения — `URLConnection.guessContentTypeFromName` (stdlib).

## Архитектура

JVM-модуль `:central` (Kotlin, coroutines, OkHttp; `org.json` — платформенный на
Android, на JVM только compileOnly/тесты): модели и ошибки, `RestClient`,
`WsClient`, `Account`, `SyncEngine`, `CentralService` + интерфейс `CentralStore`.
`VaultCentralStore` в `:app`. Адрес сервера — параметр входа (домен сменится).

## Тесты

- JVM: разбор ответов, `wsUrlFor`, время; **живые тесты против настоящего
  `vsc_web`** (пропуск без `VSC_WEB_PYTHON`): вход/регистрация, создание и вход по
  коду, отправка и доставка через `/ws` второму аккаунту, правка/удаление,
  отсутствие дублей после повторного синка, медиа с докачкой, resume/logout,
  протухший токен.
- Эмулятор: `VaultCentralStore`.
