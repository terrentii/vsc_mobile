# Интерфейс и фон — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Рабочее приложение: разблокировка, P2P и «Центр» в UI в стиле десктопа, фоновый сервис, уведомления, настройки.

**Architecture:** `MysApp` (Application) → `AppGraph` (vault + сервисы + реактивные счётчики) → одно `MainActivity` (FragmentActivity, `FLAG_SECURE`) с Compose-экранами; `MysService` — foreground `remoteMessaging`. Логика режимов — готовые `:p2p`/`:central`.

**Tech Stack:** Compose foundation (BOM 2025.06.00), androidx.biometric 1.1.0, core-ktx, compose ui-test.

Спека: `docs/superpowers/specs/2026-10-22-ui.md`. Ветка поверх `feat/central`.
